# Everyday Puzzle Arcade

Four classic logic-puzzle mechanics, each reskinned as an everyday
errand so the underlying logic stays approachable: a lost dog finding
its way home, a backyard golf shot, a plumber's pipes, and moving-day
box packing. Built with Phaser 3, landscape (1920×1080), no build step.

For what each game is likely to teach a child (through Class 8), see
[`EDUCATIONAL_VALUE.md`](EDUCATIONAL_VALUE.md).

## The four games

### 🐕 Homeward Bound — road network (Path Shift)
Tap a road tile to rotate it 90°. Every tile needs to end up pointing
the right way so the whole grid forms one continuous road from the dog
(top-left) to home (bottom-right). Generated from a random spanning
tree, so it's always solvable — the tiles are just scrambled rotations
of the one true solution.

### ⛳ Backyard Golf — gravity sliding (Gravity Blocks)
Tilt the green with the arrow keys, WASD, or by tapping a cell; the
ball rolls in that direction until it hits a rock or the edge. Get it
into the hole. Rocks are scattered randomly at generation time, then
checked with a reachability search — if a layout would trap the ball,
it's regenerated until the hole is actually reachable.

### 🚰 Pipeline — connect-the-pipes (Color Flow)
Drag each colored pipe from its SOURCE to its matching OUTLET. Cells
are exclusive: no two pipes may ever share or cross a cell, so routes
have to be planned around each other, not just drawn independently
(the standard "Flow Free" rule). Levels are generated by actually
drawing the mutually-exclusive solution paths first and reading off
their endpoints, so a solution is guaranteed to exist by construction.

### 📦 Moving Day — shape packing (Shape Packing)
Select a box from the scrollable inventory, rotate it, then load it
into the truck bed. Fit every box in with no overlap. Boxes are cut
directly from a full partition of the target grid, so placing every
box back at its original position and rotation is always a valid
solution — the puzzle is solvable by construction.

## Shared features (all four games)

- **10 deterministic levels per game** — each level's layout comes from
  a seed derived from the session + game + level number, so Previous/
  Next always return to the exact same puzzle within a session.
- **Undo / Redo** — a generic history stack in `GameScene`; every
  puzzle module just calls `scene.record()` immediately before it
  mutates its own state.
- **Hint** — reveals one legal step toward the solution rather than the
  whole answer, so it's a nudge, not a cheat sheet.
- **Win animation** per game (the dog walks the solved road home, the
  ball drops into the hole, the pipes pulse, the truck bed flashes)
  before the "Solved!" popup appears.
- **A dedicated accent color** per game (amber / green / blue / purple),
  used for the active tab, the board frame, and the objective panel —
  makes the four games visually distinct at a glance.

## Running it

Because the game is loaded as ES modules (`<script type="module">`),
it needs to be served over `http://`, not opened directly as a
`file://` URL. From this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## What's where

```
index.html                    <- page shell, loads Phaser from CDN + js/main.js as a module

js/main.js                    <- Phaser.Game config: 1920x1080, Scale.FIT, autoRound

js/Constants.js               <- board/sidebar layout numbers, per-game titles/objective text
js/Theme.js                   <- colors, fonts, and the four per-game accent colors
js/Utils.js                   <- seeded RNG (Rng, seedForLevel), state clone(), rot4/turnsToRotate

js/scenes/GameScene.js         <- all UI chrome (tabs, sidebar, controls, win popup),
                                  undo/redo history, level lifecycle, and input routing
                                  into whichever puzzle module is active

js/ui/Button.js                <- shared button: rounded fill, border, hover/press
                                   feedback, and an "active" state used for tabs

js/puzzles/PuzzleBase.js       <- shared contract every puzzle extends: owns `state`,
                                   draws into a fixed 600x600 local space, exposes
                                   generate/redraw/isSolved/hint
js/puzzles/PathShift.js        <- Homeward Bound
js/puzzles/GravityBlocks.js    <- Backyard Golf
js/puzzles/ColorFlow.js        <- Pipeline
js/puzzles/ShapePacking.js     <- Moving Day
```

## A few implementation notes

- **Fixed local coordinate space.** Every puzzle module always draws
  into a 600×600 square, regardless of the real screen size.
  `GameScene` positions and scales that square up via a Phaser
  container (`boardContainer.setScale(...)`) to fill the landscape
  canvas, and un-scales pointer input the same way
  (`GameScene.toBoardLocal`) before handing coordinates to a puzzle. No
  puzzle file needs to know the real canvas size.
- **Generic undo/redo.** `GameScene.history` holds only *past* states;
  the live state is always `puzzle.state` itself. A puzzle calls
  `this.scene.record()` right before mutating its state, and that's the
  entire integration — `GameScene` handles the actual undo/redo stack
  for every game the same way.
- **Solvability is generated-in, not checked after the fact**, for all
  four games (see each game's description above) — none of them can
  ship a level with no valid solution.
- **Known trade-off:** Pipeline's Hint checks each unsolved pipe with a
  simple, single-pipe search and takes the best one it finds. It
  doesn't look ahead at whether that choice might box in a *different*
  pipe, so on a packed board it can occasionally (rough order of 1-in-20
  levels) reach a point with no legal next step and ask the player to
  Undo. The puzzle itself is still always solvable from the start; a
  perfect hint would need a full backtracking solver, which was judged
  not worth the complexity/performance cost for this game.
